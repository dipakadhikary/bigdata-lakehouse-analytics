1. What Is This?

The Smart Data Platform is an enterprise-grade data lakehouse — a unified system that combines data lake flexibility, data warehouse reliability, and streaming speed into one open-source platform.

Data Lake Flexibility

Store all data cheaply at scale on S3-compatible object storage in open Parquet format.

Warehouse Reliability

ACID transactions, schema evolution, and versioned snapshots via Apache Iceberg.

Streaming Speed

Continuous CDC — every insert, update, delete captured and queryable within minutes.

Connectors Configured

Debezium CDC Source Connector

PostgreSQL → Kafka. Captures every INSERT, UPDATE, DELETE via logical replication. Topics: analytics.public.<table>. Initial snapshot + continuous streaming.

Iceberg Sink Connector

Kafka → Lakehouse. Writes versioned Parquet files to MinIO, commits snapshots via Nessie. Explicit per-table or dynamic auto-create for all source tables.

8. Data Organization — Medallion Architecture

Bronze — Raw Landing

As-is CDC replication from source. Full insert/update/delete history. Auto-populated by the pipeline — zero manual ETL.

merchants, transactions, settlements, chargebacks, kyc_documents

Silver — Cleansed & Conformed

Deduplicated, validated business entities. Standardized schemas. Quality rules applied. Ready for analytics.

payments, merchant_risk, clean_settlements

Gold — Business Metrics

Executive KPIs and aggregates. Regulatory reporting tables. Optimized for dashboard performance.

daily_gmv, payment_success_rate, settlement_summary

11. Implementation Roadmap

1
Foundation — Week 1

Deploy all 9 services via Docker Compose. Configure Debezium CDC and Iceberg sink connectors. Verify first table (merchants) flowing end-to-end: PostgreSQL → Kafka → Iceberg → Trino → Superset.

2
Core Domains — Weeks 2–3

Onboard transactions, settlements, chargebacks, and KYC tables. Complete Bronze layer. Build operational dashboards in Superset for payments and merchant monitoring.

3
Analytics Maturity — Weeks 4–6

Build Silver (cleansed entities) and Gold (KPI aggregates) layers via Trino SQL. Deliver executive dashboards: daily GMV, payment success rate, settlement summary, merchant onboarding funnel.

4
Production Hardening — Weeks 7–10

Enable TLS, SSO/LDAP, secrets vault. Migrate storage to cloud S3. Deploy on Kubernetes with high availability. Implement Prometheus + Grafana monitoring and alerting.
